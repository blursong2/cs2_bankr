# 한섭차단
카스가 너무 찐따게임이라 솔랭밖에 못하겠습니까

발로란트 좆게이게임 나이제한때문에 어떻게든 하고싶다고 카스 넘어온 애새끼들 그만 보고싶습니까

글옵부터 지금까지 프라임 논프라임 가리지 않고 있던 늙크크 병신 캐주얼 좆목충새끼들도 그만 보고싶습니까

윤로빈 뉴템 준현 개 병 신 앺갤 고닉 찐따 핵새끼들 적당히 보고싶습니까

스캘퍼 꽃마냥 여자만 보이면 원순행동하는 병신 장애인새끼들도 그만 보고싶습니까
